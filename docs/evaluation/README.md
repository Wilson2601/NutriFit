# Evaluation materials (FYP 2, Chapter 3.3.3)

| Metric | Material |
|---|---|
| Calculation accuracy | Automated tests in `backend/tests/` (hand-calculated reference values in `test_optimizer.py`). Run `python make_test_report.py` in `backend/` to produce `TEST_REPORT.md`. |
| System Usability Scale | `SUS_QUESTIONNAIRE.md` + scoring in `backend/app/evaluation.py` |
| User satisfaction | `SATISFACTION_QUESTIONNAIRE.md` |
| Task completion rate | `TASK_CHECKLIST.md` |

No participant data, scores or ratings are included. They must come from real testing.
